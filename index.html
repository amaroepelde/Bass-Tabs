Tabs de bajo

Escribí una tab de bajo

Tocá una casilla y escribí el número de traste. Con las flechas te movés entre cuerdas y posiciones.

Teclas: números 0 a 24 (dos dígitos seguidos para trastes altos), x para nota apagada, flechas para moverte, Borrar para vaciar la casilla y Ctrl+Z para deshacer.

Canciones

Las tabs guardadas en este navegador. Elegí una para verla o seguir editándola.
